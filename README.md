# 🍊 TangerineWin

أداة لويندوز مستوحاة من Tangerine لماك: امسك **Shift** واسحب أي ملف في مستكشف الملفات أو سطح المكتب، فبيطلع حوالين المؤشر **menu دائري**. أفلت الملف على الخيار اللي بدك إياه وبيتنفّذ فوراً، والملف الجديد بينحفظ جنب الأصلي.

> ملاحظة: هاد مشروع جديد مكتوب من الصفر لويندوز، مش نسخة رسمية من Tangerine. ما قدرت أفتح موقع tangerineformac.com أثناء الكتابة، فالميزات مبنية على وصف الأداة من مراجعات منشورة.

## الاستخدام

1. شغّل `TangerineWin.exe`. بيظهر أيقونة 🍊 في منطقة الإشعارات (بجنب الساعة).
2. في Explorer أو على سطح المكتب: **ابدأ اسحب أي ملف، وبعدين اضغط Shift أو Ctrl**. بيطلع menu دائري حوالين المؤشر، وبيضل مفتوح لحد ما تفلت الملف.
   - **Shift = تحويل الصيغة.**
   - **Ctrl = أدوات الملف.**
   - بتقدر تبدّل بين الاثنين وإنت لسا ماسك الملف.
3. أفلت الملف على الخيار اللي بدك إياه. الملف الجديد بينحفظ جنب الأصلي، وبيطلع إشعار. اضغط عليه لفتح مكانه.

الـ menu بيتغير حسب نوع الملف:

| نوع الملف | Shift (تحويل) | Ctrl (أدوات) |
|---|---|---|
| صورة | PNG, JPG, BMP, TIFF, GIF, PDF | ضغط (تصغير الحجم), **قص** (Crop), Metadata (حذف بيانات EXIF/GPS), ZIP |
| PDF | Word, صور PNG | ضغط PDF*, ZIP |
| Word / Excel / PowerPoint | PDF | ZIP |
| أي ملف أو مجلد ثاني | (ما في) | ZIP |

الخيارات اللي ما بتناسب الملف بتنشال من الـ menu (مثلاً ما بيطلع "PNG" لملف PNG أصلاً).

بالضغط يمين على أيقونة الـ tray: تفعيل/إيقاف، التشغيل مع ويندوز، خروج.

\* ضغط PDF الحقيقي بيحتاج Ghostscript منزّل.

### القص (Crop)
اسحب صورة، اضغط **Ctrl**، وأفلتها على **قص**. بتفتح نافذة: حرّك المستطيل، أو اسحب المقابض لتغيير الحجم، أو ارسم مستطيل جديد على الصورة. اختار نسبة (1:1، 4:3، 16:9...) أو خليها حرة، ثم **حفظ** (أو Enter). بيتحفظ `اسم_crop` جنب الأصلية، وEsc للإلغاء.

### اللي لسا مش موجود
WEBP وAVIF وHEIC كصيغ ناتجة، وأدوات Annotate وEdit وRedact وAdd BG. وكمان شاشة إعدادات لتغيير المفاتيح.

## ⚠️ ويندوز بيحظر البرنامج (Smart App Control / SmartScreen)

الـ exe غير موقّع برخصة رقمية، فممكن ويندوز يحظره:

- **SmartScreen:** اضغط **More info** ثم **Run anyway**.
- **Smart App Control** (ويندوز 11): ما في زر تجاوز. إيقافه قرار أمني يخصك، وفي بعض نسخ ويندوز ما بترجع تفعّله بدون إعادة تثبيت. لا تطفيه على جهاز عمل أو جهاز عليه بيانات حساسة.
- **أجهزة الشركات:** البرنامج بيستخدم mouse hook عام. شغّله فقط على جهازك الشخصي، أو بعد موافقة قسم الـ IT.
- للتوزيع على ناس ثانيين لازم توقيع كود (مثل Azure Trusted Signing).

## 🔒 القيد على القرص C: فقط

البرنامج بيشتغل **بس على ملفات القرص C:** (سطح المكتب والتنزيلات والمستندات العادية). أي ملف على قرص ثاني (مثل Z: أو أي سيرفر) أو على مسار شبكة (`\\server\share`) بيتم رفضه:

- أول ما تحط الملف فوق الـ menu، بيقرأ البرنامج **اسم المسار فقط** (نص). وإذا كان خارج C: بيظهر "ممنوع" ولا بيفتح الملف ولا بيقرأ منه شي.
- فحص ثاني قبل أي تنفيذ، فلو فشل الفحص الأول ما بيتنفذ شي.
- لو سحبت عدة ملفات وواحد منهم خارج C: بيتم رفض الكل.
- الـ symlink والـ junction اللي عالـ C: وبتشاور على قرص ثاني بيتم رفضها. وعند عمل ZIP لمجلد، المجلدات المشبوكة بـ junction بيتم تخطيها.
- الملفات الناتجة والملفات المؤقتة بتنكتب على C: (جنب الأصلي وفي `%TEMP%`).
- لتغيير الأقراص المسموحة عدّل `AllowedDrives` في `PathGuard.cs`.

حدود: إذا مجلد سطح المكتب أو المستندات معمول له redirect لسيرفر، بيعتبره البرنامج خارج C: وبيرفضه. وهاد القيد بيخص هالبرنامج فقط، وما بيحمي جهازك من برامج ثانية.

## الحصول على البرنامج جاهز (بدون ما تثبّت شي)

المشروع فيه GitHub Actions بيبني ملف `TangerineWin.exe` لحاله على سيرفرات ويندوز.

1. أنشئ repository جديد على GitHub وارفع محتويات هاد المجلد عليه (خلّي `TangerineWin.csproj` و`.github` بجذر الـ repo).
2. افتح تبويب **Actions**. البناء بيشتغل تلقائياً مع كل push. أو اختار **Build Windows app** ثم **Run workflow**.
3. بعد ما يخلص (دقيقتين تقريباً) افتح التشغيلة ونزّل **TangerineWin-win-x64** من قسم Artifacts. جواها `TangerineWin.exe`، وما بيحتاج تثبيت .NET.

**لعمل Release رسمي بنفس الرابط الثابت:**

```bash
git tag v1.0.0
git push origin v1.0.0
```

بيظهر الملف في صفحة **Releases** للـ repo.

> هاد الكود انكتب بدون ما أقدر أبنيه أو أجرّبه على ويندوز. لو البناء الأول فشل، افتح تفاصيل الخطوة الحمرا في Actions وابعتلي رسالة الخطأ وبصلحها.

## البناء على جهازك (اختياري)

بدك Windows 10/11 و[.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```bash
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish
```

الناتج: `publish/TangerineWin.exe`.

## المتطلبات الاختيارية لبعض الميزات

- **Word / Excel / PowerPoint إلى PDF، وPDF إلى Word:** Microsoft Office منزّل، أو [LibreOffice](https://www.libreoffice.org/) كبديل مجاني.
- **ضغط PDF حقيقي:** [Ghostscript](https://ghostscript.com/releases/gsdnld.html). بدونه خيار "ضغط" بيعمل ملف ZIP.
- **PDF إلى صور:** ما بيحتاج شي، بيستخدم مفسّر PDF المدمج في ويندوز.

## كيف بيشتغل

- `DragHook.cs`: mouse hook وkeyboard hook عامين: بيلقطوا بداية سحب ملف فوق Explorer أو سطح المكتب، وضغطة Shift أو Ctrl أثناء السحب.
- `Program.cs`: بيتأكد عبر UI Automation إنك بتسحب ملف فعلاً، وبيعرض الأيقونة في الـ tray.
- `RadialWindow.cs`: نافذة شفافة بدون تفعيل، كل قطاع فيها هدف إفلات (drop target). بترجّع دائماً Copy حتى Explorer ما يحذف الأصل (Shift + سحب عادةً يعني نقل).
- `Actions.cs`: تعريف الخيارات لكل نوع ملف ولكل وضع (Shift أو Ctrl). لإضافة خيار جديد أضف `ActionDef` للقائمة المناسبة.
- `Converters.cs`: التحويلات (WPF imaging، PDFsharp، Office COM، LibreOffice، Ghostscript، ZIP).

## قيود معروفة

- ما بيشتغل فوق نوافذ Explorer المرفوعة بصلاحيات Administrator.
- الـ menu بيعرض حتى 6 خيارات حسب نوع الملف. زيادة الخيارات بتحتاج تعديل بسيط في `Actions.cs`.
- أول إصدار: ما في إعدادات للجودة أو الحجم، القيم ثابتة في `Converters.cs`.
